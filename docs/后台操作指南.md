# 易云 CMS・后台操作指南

## 〇、后台界面风格（云优风格）

- 顶部深蓝导航条（预览前台/静态生成/语言切换/当前管理员/退出）；左侧深色侧边栏按组显示菜单。
- 主色为云优蓝 `#2d8cf0`；表格简洁留白，表头浅灰。
- **操作列单行**：栏目管理/内容管理等列表的操作按钮（内容/发布/编辑/删除等）固定单行显示，不换行。
- **菜单管理**（系统设置 → 菜单管理）：按菜单分组、横线分行列出全部菜单项，每项右侧 iOS 风格开关，点击即时显示/隐藏侧边栏菜单。
- **菜单管理 v3.22（拖动排序 / 改层级 / 行内改名 / 新增 / 删除）**：①**行内改名**——直接点击菜单名称变为输入框，输入新名称后回车或点击其他位置即保存（Esc 取消）；②**拖动排序**——按住菜单行（名称区域）拖动到目标行上方/下方松开，组内顺序即变（子项可在组内上下移动）；③**拖动改层级**——把子项行拖到某个一级菜单组标题上松开，该子项即移入该组（如把「会员管理」从内容管理拖到商城管理）；一级菜单组也可互相拖动排序；④**数字排序**——每行右侧数字输入框直接改序号（回车/失焦保存），数字越小越靠前；⑤**新增菜单**——顶部「＋ 新增一级菜单」按钮弹出表单：一级菜单需填名称（内部标识 key 不填自动生成，可选图标），新增后自动显示在侧边栏末尾；每个一级菜单组标题右侧的 ＋ 按钮可在该组下新增子菜单（需填名称 + 路由地址，如 content/index）；⑥**删除菜单**——子菜单行右侧 ✕ 删除该子项；一级菜单组右侧 ✕ 删除整组（**其下全部子菜单将一并删除**），均有确认弹窗；⑦改名/排序/改层级/新增/删除均即时写入数据库（`yy_admin_menu` 表），刷新与重启后保持；侧边栏显隐开关仍走全局配置 `admin.menu_hidden`，关闭状态的菜单项仅在侧边栏隐藏，菜单管理页始终可见可编辑。
- 状态标签（发布/草稿/显示/隐藏/是/否等）单行不换行，点击可切换。
- **全平台自适应（v3.19）**：后台全站响应式布局——
  - **≥1920 超宽屏**：侧边栏加宽至 256px、内容区加宽居中（最大 1720px）、字号/控件放大；
  - **1200~1920 笔记本**：侧边栏 200px、表单控件适度收紧；
  - **≤992 平板横屏/小屏**：侧边栏收起为**抽屉**（左上角汉堡按钮展开/收起 + 遮罩，点遮罩/Esc/导航项自动关闭），主区全宽；
  - **≤768 手机/平板竖屏**：表单竖排（标签在上输入在下）、表格横向滚动、统计卡两列、工具按钮压缩、昵称隐藏、语言下拉改为屏幕固定定位；
  - **≤576 小手机**：仅保留语言切换与退出按钮，其余头部按钮隐藏。
  - 实现：百分比 + CSS 变量（`--sidebar-w`）+ `media queries`，无 JS 框架依赖；`admin.css` 末尾 v3.19 响应式块。


- **侧边栏不刷新框架（v3.21）**：后台改为「外层框架 + 右侧 iframe 内容区」。点击左侧菜单仅右侧内容区刷新，侧边栏保持不动（滚动位置、展开状态不丢失）；iframe 内页面只渲染内容块（不再重复渲染侧边栏/顶栏，杜绝“iframe 套后台”嵌套）。iframe 内任意跳转（含表单提交、JS 跳转）会自动补 `frame=1` 参数保证单层框架；会话超时自动整体跳回登录页。
- **菜单树入库（v3.22）**：菜单管理升级为「菜单树持久化」——新增数据表 `yy_admin_menu`（id/pid/key/name/icon/url/sort），后台菜单以数据库为权威源（空表时自动从默认菜单导入 43 条种子）；拖动排序/改层级/行内改名/数字排序直接写库，不再依赖 PHP 代码数组。系统开关（会员/商城/客服/评论）与显隐配置照常生效。升级方式：执行 `database/upgrade_v322.sql` 建表（或直接访问一次菜单管理页自动建表+导入种子）。

## 一、登录与退出



1. 浏览器访问 `/admin/`，进入登录页。

2. 输入用户名、密码、**验证码**，点击登录。

3. 登录成功进入控制台；顶栏右上角可：

* **切换录入语言**（下拉列出全部已启用语言，切换后后台所有录入按该语言进行）

* **预览前台**（主语言跳站点首页 `/`，其他语言跳 `/{lang}/`）

1. 退出：顶栏「退出登录」。

> 若提示验证码错误：刷新验证码图后再输入；仍不行清空 
>
> `runtime/session`
>
>  后重试。

## 二、语言版本管理（多语言核心）

路径：**系统设置 → 语言版本*** **添加语言**：填语言代码（如 `ru`，前台 URL 前缀用）、语言名（如 俄语）、模板文件夹名（如 `ru`）、排序。保存后系统**自动克隆**默认语言的**全部数据表**（动态枚举 `yy_{默认语言}_*` 所有表：栏目/内容/模型/字段/留言/块/广告/链接/设置/评论/收藏/搜索日志/素材库等）并复制默认站点设置与默认留言板；新建语言的栏目 / 内容 id **从 1 开始**，与 cn/en 各自独立。

* **复制模板（v3.18）**：语言列表每行「复制模板」按钮 → 输入源语言/站群站点别名（如 `cn`、`shenyang`）→ 把 `template/源` 整个文件夹（含 PC + wap + css/js/img）复制到 `template/该语言`，覆盖同名文件。**多语言模板无需手动建目录**：先添加语言（自动建表）→ 点「复制模板」从现有语言/站点复制即可；也可在「站群管理」行内「复制模板」按钮同样操作。

* **编辑语言**：可改语言名、模板文件夹名、flag。

* **设为默认**：点「默认」，设为默认的语言即**主语言**—— 静态生成时主语言首页放站点根目录、栏目放 `{lang}/` 文件夹、URL **无语言前缀**（由伪静态隐藏）；其他语言放 `{lang}/` 文件夹、URL **带前缀**。

* **启用 / 停用**：停用后前台不可访问该语言、URL 前缀不再路由。

* **排序**：影响前台语言切换列表顺序。

* **清语言缓存**：修改后点「清缓存」使配置立即生效。

## 二·A、站群管理（v3.18：路径模式 + 域名模式）

路径：**系统设置 → 站群管理**（菜单常显；站群开关在 系统设置 → 网站设置 → 站群设置(全局)）

### 站群开关

* **关闭（默认）**：单站点模式，所有访问按主语言/其他语言前缀处理。
* **开启**：站群模式。**路径模式**站点：`本域名 + 英文别名` 即进入对应站点（如 `http://newcms.com/shenyang/` 为沈阳站），无需绑定二级域名；**域名模式**站点：按 Host 命中（支持精确域名与通配 `*.example.com`）。

### 添加站点（路径模式，推荐）

「添加站点」→ 站点模式选「**路径模式**」→ 填站点名称（如 沈阳站）、**路径别名**（2~20 位小写字母，如 `shenyang`）→ 选择**复制来源**（源语言/站点，默认主语言）→ 勾选「复制数据库（整套表含数据）」与「复制模板文件夹（PC+手机版）」→ 保存。

保存后自动完成三件事：

1. **注册语言版本**：code = 别名（如 `shenyang`），模板文件夹 = 别名，自动出现在后台顶栏语言切换与「语言版本」列表中；
2. **克隆整套数据库**：把源语言的全部数据表（栏目/内容/留言/留言板/自定义块/广告位/友情链接/内容模型/字段/设置/评论/收藏/搜索日志/素材库/审核日志等）克隆为 `yy_{别名}_*`，**含全部数据，id 各自从 1 开始**，与主站完全独立；
3. **复制模板文件夹**：`template/源` → `template/{别名}`（含 PC + wap + css/js/img），前台立即可渲染。

### 站点列表操作

* **访问**：路径模式站点行内「访问」按钮直接打开 `/{别名}/` 前台。
* **复制模板**：行内「复制模板」→ 输入源语言/站点别名 → 重新复制模板文件夹（覆盖同名文件，用于模板升级后同步）。
* **编辑**：可改名称/状态/排序/备注；路径别名与复制仅新建时生效。
* **删除**：删除站点；路径模式站点同时**停用**其同名语言版本（数据表保留，不误删数据）。
* **编辑站点（v3.21）**：站点名称可随时修改；**站点别名（访问路径）编辑时锁定不可改**（需改名请删除后重建，避免破坏前台 URL 与已生成静态文件）；启用语言以表单勾选为准（与站点自身语言合并），不再因“别名与语言代码重复”误报保存失败。

### 站群前台访问规则

* 站点入口：`/{别名}/`（如 `/shenyang/`）；站内栏目/详情/单页链接自动带 `/{别名}/` 前缀（如 `/shenyang/pro/pro1/`），与主站完全隔离。
* 站点内语言切换：按站点「启用语言」白名单显示；路径模式站点默认白名单只有自身别名语言，可在编辑页勾选其他语言（如 cn/en）扩展。
* 动态预览：未生成静态时访问 `/{别名}/lists?id=xx` 等动态地址正常；`/{别名}/栏目路径/` 需**生成静态页**后访问（见静态页生成）。

### 静态生成（站群）

「静态页生成」→ 语言选择 `shenyang`（或站群别名）→ 一键生成：全部静态页输出到 `public/{别名}/`（首页 `public/{别名}/index.html`、栏目 `public/{别名}/pro/index.html` 等），URL 即 `/{别名}/...`，与主站静态互不干扰。生成时自动注入站点上下文，站内语言切换/链接按站点白名单渲染。

## 二·B、站群推送与分站管理员（v3.20）

路径：**扩展功能 → 推送管理**；发起入口：**内容管理 → 勾选内容 → 推送到站点**。

### 核心概念

* **站点即语言**：主站 = `main`（全局默认语言）；分站 = 站点别名（如 `shenyang` 站 = `shenyang` 语言）。跨站推送 = 跨语言复制 + 推送状态机。
* **推送状态**：待处理（0）→ 已采纳发布（1）/ 已拒绝（2）/ 已撤回（3）。采纳/通过后内容以**副本**方式写入目标站点（目标语言表新增一条记录，标题/富文本/图集/时间等全字段保留，目标栏目可另选）。

### 一、分站 → 主站推送（投稿）

1. 后台切到分站语言（顶栏语言选 `shenyang`），进入内容管理，勾选要推送的内容（可多选）；
2. 点击批量操作「**推送到站点**」→ 选择目标站点（主站 / 其他语言站）→ 选择目标栏目 → 提交；
3. 提交成功提示「等待主站管理员审核」。此时记录进入主站「待我处理」。

### 二、主站 → 分站推送（下发）

1. 主站内容管理勾选内容 → 「推送到站点」→ 目标站点选分站（如 `shenyang`）→ 选分站目标栏目 → 提交；
2. 分站管理员登录（语言切到分站）→ 推送管理「待我处理」→ **采纳/通过** → 选择目标栏目（默认推送时选的栏目）→ 提交；
   - **采纳/通过弹窗（v3.21 美化）**：弹窗显示来源文章标题、来源栏目、处理说明；目标栏目下拉为**树形缩进**（`├─` + `（#栏目id）`），一键定位目标位置；通过后**自动跳转到目标内容编辑页**，可直接预览校对与修改。   - **v3.21.1（推送优化）**：①目标栏目下拉改为显示**完整栏目树**（顶级/二级/三级全部展开，树形缩进 `├─`），发起推送（内容管理→推送到站点）与采纳弹窗均生效；②采纳/通过弹窗**默认选中发起方推送时选择的目标栏目**，审核人无需重新选择；③弹窗改用标准 `m-head/m-body/m-foot` 结构（内容区 20px 内边距），修复弹窗内容贴边无间距问题。
3. 内容即以副本写入分站内容表（catid 为目标栏目），分站前台立即可见；开启静态模式时自动刷新分站静态页。

### 三、审核 / 拒绝 / 撤回

* **采纳/通过**：仅「待我处理」且当前登录站点为目标的站点管理员可操作；通过时可选改目标栏目。
* **拒绝**：必须填写拒绝原因（如「分站内容与本站重复，暂不接收」），拒绝后发起方可在「我发起的」看到状态「已拒绝」与原因。
* **撤回**：仅发起方可撤回「待处理」记录（如推送错了目标栏目），撤回后状态为「已撤回」。

### 四、分站管理员（站点/语言范围）

1. **角色管理**：沿用现有角色（投稿员/审核员/留言查看/SEO优化等），`need_audit`（发布需审核）开关同样适用；
2. **管理员管理** → 新增/编辑管理员 → 设置角色（如投稿员）→ **可管理站点/语言**：勾选分站（如 `沈阳测试站（shenyang）`），**留空 = 可管理全部站点**；
3. 保存后该管理员登录：顶栏语言**只显示被授权的站点/语言**（如只有 `SHENYANG`），左侧菜单按角色权限（投稿员仅内容管理），内容管理只看到该分站的栏目与内容；
4. 分站管理员同样可发起推送到主站，由主站管理员审核；也可对主站下发到分站的内容执行采纳/拒绝。

### 演示数据说明

库中 `yy_push` 保留两条已采纳演示记录（主站→分站、分站→主站），可在「全部记录」查看来源→目标、状态、发起人、审核人与时间。

## 三、栏目管理

路径：**栏目管理**（树形展示，一级栏目左侧有加号可展开二级 / 三级，顶部有「全部展开 / 全部收起」按钮）

### 列表页操作（无需进编辑页即可完成）



* **树形折叠**：一级栏目左侧加号展开 / 收起子栏目；顶部按钮一键展开 / 收起全部。

* **行内编辑**：直接点「名称 / 别名 / 排序 / 导航 / 显示」单元格即可修改，失焦或回车即保存生效，保存后取消输入状态。

* **发布内容**：栏目右侧「发布内容」→ 进入内容添加页并**自动选中该栏目**。

* **内容管理**：栏目右侧「内容管理」→ 进入只显示该栏目（含子栏目）的内容列表。

* **批量添加栏目**：工具栏「批量添加」→ 弹层逐行填写栏目名称（别名按拼音自动生成）、下拉选父栏目、选「列表模板 / 内容模板」→ 保存。

* **跨语言复制（顶部按钮）**：勾选要复制的栏目（可多选，被勾选栏目的**整棵子树**——含所有子栏目与各自内容——会一起复制并**保持原父子层级**）→ 工具栏「跨语言复制」→ 弹窗选择目标语言、选择放置位置（**顶级** 或放到目标语言的某个一级 / 二级栏目下）→ 复制后在目标语言中翻译。勾选父子栏目时只复制最顶层，避免重复。

* **删除**：删除栏目（有内容的栏目会提示）。删除默认移入回收站；有子栏目或内容时可勾选「连同子栏目与内容一起删除」（级联移入回收站，可整体恢复）。顶部「回收站」按钮进入栏目回收站（显示删除时间），可恢复 / 彻底删除。

### 列表页

* **批量操作**：置顶 / 取消置顶、推荐 / 取消推荐、热门 / 取消热门、发布 / 下架 / 取消下架、删除 —— 均可批量，也可单条点状态切换。

* **发稿人 / 审核人（投稿审核）**：列表「发稿人/审核人」列与**内容编辑页**（标题下方信息条）均显示昵称；编辑页未审核时显示「审核人：待审核」，审核后显示审核人与审核时间。发稿人 = 创建该内容的账号；审核人 = 将该内容从草稿改为发布的账号。**管理员直接发布时发稿人 = 审核人（同人）**；投稿员发布的草稿无审核人，待管理员审核发布后自动记录。

* **审核流程（需审核角色，v3.6 全闭环）**：若你的角色在「角色管理」中开启了「发布需审核」，发布内容时系统**自动进入「待审核」**（提示"已提交审核（待审核）"）→ 审核人（超级管理员 / 普通管理员）在内容列表用顶部状态筛选选「**待审核**」→ 点该行操作列的「**审核**」按钮，弹出审核对话框，可看到**第几次提交**与完整时间线（历次提交 / 驳回原因 / 修改说明 / 审核通过）→ 点「**审核通过**」发布（自动记录审核人 / 审核时间，前台立即可见）；或填「**驳回原因**」点「驳回」→ 内容回到投稿人侧显示「已驳回」（原因红字提示）。
* **驳回与重新提交（v3.6）**：被驳回后，投稿人编辑该内容可见驳回原因与「修改说明」输入框 → 修改内容后填写修改说明（可回应驳回原因）→ 保存即**重新进入待审核**（提交次数 +1）→ 审核人再次打开审核对话框，可见「第 N 次提交」与历次原因 / 说明，可再次驳回（追加新原因，历史原因保留）或审核通过。
* **状态与筛选（v3.6）**：内容列表状态列三态显示——「待审核」（黄）、「已驳回」（红，鼠标悬停显示驳回原因）、发布 / 草稿（可点击切换）；顶部状态筛选新增「待审核」「已驳回」快速过滤；审核操作仅免审核角色可见（投稿员等需审核角色无审核按钮）。
* **内容审核开关（全局设置组包含：前台代码提示开关、**后台无操作自动退出**（30分钟/1小时/6小时/自定义，默认1小时，无操作达到时长自动退出登录并在登录页提示）、后台路径、静态模式、上传大小与类型限制。
全局设置）**：网站设置 →「内容审核(全局)」→「内容审核」选择开启/关闭。
  - **开启**：投稿角色发布进入待审核，管理员/审核角色可审核通过 / 驳回（填原因），编辑页显示「审核操作」区与「操作记录」时间线，列表显示待审核/已驳回状态与审核按钮。
  - **关闭**：所有角色发布即上架（不需要审核），编辑页不显示驳回原因框 / 审核操作区 / 操作记录时间线 / 修改说明，列表状态列只显示「发布 / 草稿」两个状态（点击直接切换，用于上架与下架文章），筛选无「待审核 / 已驳回」。
* **功能开关（v3.16，网站设置 → 功能开关(全局)）**：五个系统总开关，均默认「开启」：
  - **会员系统（member.open）**：关闭后前台 `/member/*`（登录/注册/会员中心/钱包等）全部显示「功能未开启」提示页；后台「会员管理 / 会员设置」菜单自动隐藏。
  - **商城系统（shop.open）**：关闭后前台 `/shop/*`（商品/购物车/结算/订单/支付/售后）禁止访问；后台「商城管理」整组（商品价格/订单管理/售后管理/钱包管理/支付设置）菜单自动隐藏；前台列表页与详情页不再显示商品价格与购物车入口。
  - **客服系统（service.open）**：关闭后前台 `/service/chat` 禁止访问；后台「客服会话」菜单自动隐藏；全站「在线客服」入口（顶栏 / 首页 / 产品详情 / 列表侧栏）隐藏。
  - **评论功能（comment.open）**：关闭后前台详情页不注入评论数据、评论区块整体隐藏、`/show/comment` 提交接口拒绝；后台「评论管理」菜单自动隐藏。

  - **静态页联动**：静态页生成时同样按开关跳过价格/评论/收藏数据注入，模板功能入口按 `$sys_open` 条件隐藏，无需手工改模板。
* **审核入口（v3.6）**：审核有两个入口——① 内容列表点「审核」按钮弹出对话框；② **内容编辑页**（免审核角色编辑待审核/已驳回内容时）顶部「审核操作」区，填原因可直接驳回 / 审核通过。
* **变化日志（v3.6）**：审核通过后再把内容改为草稿 / 下架（编辑保存、行内切换、批量下架），会记录一条「下架/存草稿」日志；编辑页「操作记录」时间线完整展示提交 / 驳回（含原因）/ 审核通过 / 下架存草稿全部变化。
* **审核日志表（v3.6）**：每次提交 / 驳回 / 通过 / 下架均写入 `yy_{语言}_content_audit_log`，全程留痕（type：1 提交、2 驳回、3 通过、4 下架/存草稿），时间线按时间正序展示，多次驳回不覆盖历史。
* 提示：管理员 / 超级管理员直接发布的内容自动记为「审核通过」（无待审核环节），发稿人 = 审核人（同人）。

* **预览**：点「预览」看前台详情；下架文章后台预览可见，但复制链接给未登录用户访问会提示「内容未公开」并 3 秒后返回首页（不报错）。

## 十二、静态页生成

路径：**静态页生成**（或右上角「静态生成」按钮，一键生成全部语言全站静态文件，含首页/栏目/内容；生成期间页面较多时等待提示完成即可）

**静态页目录规则（v3.2）**：



* **主语言（默认语言）**：首页 `index.html` 在站点**根目录**；栏目 / 内容静态页放**主语言文件夹**（`cn/news/`、`cn/about.html`、`cn/news/12.html`），前台 URL **无语言前缀**（`xxxx.com/news`，浏览器链接不体现 `cn`），前缀由伪静态隐藏（Nginx `try_files` / Apache RewriteRule）。

* **其他语言（en）**：`en/index.html`、`en/news/`、`en/about.html`，前台 URL **带前缀**（`xxxx.com/en/news`）。

* 静态目录按栏目 \*\* 别名 (ename)\*\* 生成；改别名后重新生成即按新别名建目录。

* 前台栏目链接自动按此规则：主语言无前缀、其他语言带前缀。

* **栏目静态URL规则开关（base.static\_url\_mode，系统设置 → 静态页设置）**：
  * **精准链接（accurate，默认）**：栏目与内容静态路径拼接全部祖先别名，前台 URL = 域名 + 一级 + 二级 + 三级 + 详情页（如 `xxxx.com/pro/pro1/1/16.html`）；单页也带父层级（如 `/aboutus/about.html`）。
  * **精简链接（compact）**：只保留最后栏目与详情页（如 `xxxx.com/pro1/1/16.html`）。
* 列表栏目链接统一**带尾斜杠**（`/news/`、`/pro/pro1/`），避免 Nginx/Apache 对目录做 301 时暴露主语言前缀。
* 伪静态规则文件（`public/nginx.htaccess` 与 `public/.htaccess`）由系统**自动生成**（`sync_pretty_firewall`）：把主语言代码写入规则，实现主语言无前缀隐藏、其他语言带前缀。改主语言或重新生成静态时自动更新。
* 切换 URL 规则或栏目别名后，需到「静态页生成」**重新生成**全站静态页。

### 十五·A-1、数据范围权限（栏目范围 / 留言板范围）

- **栏目范围**：勾选该角色可管理的栏目（**自动含其全部子栏目与内容**）。留空 = 全部栏目。

  - 受限角色在栏目 / 内容管理中的栏目下拉树也只显示权限栏目，无法越权访问未授权栏目。
- **留言板范围**：勾选该角色可查看的留言板。留空 = 全部留言板。

- **超级管理员**恒为全部范围，不受数据范围限制。

  3. 为**每个组合单独填价格与库存**（留空则前台该组合显示商品级价格）；
  4. 保存后写入 `yy_shop.specs` 的 `_sku` 键，前台详情页自动出现规格下拉，选择即联动价格 / 库存 / 可购数量，库存为 0 的组合前台禁止购买。
- **无规格商品**：继续使用列表行的商品级价格与库存。

### 订单管理

- 订单状态流转：**待支付**（`status=0`，可关闭/标记取消）→ **待发货**（`1`，已支付）→ **已发货**（`2`，填写快递公司 + 快递单号后自动切换）→ **已收货**（`3`，会员确认）。
- **线下转账确认收款**：支付方式为「线下转账」的订单，会员转账后在待支付列表点「确认收款」→ 订单直接变为待发货。
- 订单详情展示商品（含所选规格文本）、金额、收货信息、支付方式、时间线；`refund_status` 显示售后关联状态。

### 售后管理

- 会员在订单详情发起售后（退货退款，填金额与原因）。
- 审核操作：
  - **同意并退款**：自动将退款金额计入会员**钱包**；若该订单走的是**真实微信 / 支付宝支付**且商户已配置，会先调用支付平台**原路退款**（微信退款需在支付设置填写 apiclient_cert.pem / apiclient_key.pem 服务器绝对路径；支付宝无需证书），原路退款失败则提示改用线下处理。
  - **同意**：标记同意（等待退货寄回）。
  - **拒绝**：必须填写理由，会员可见。

### 钱包管理

- 查看全部会员钱包余额 / 冻结 / 累计收入 / 累计提现；可手动调整余额（入账/扣减并记录流水）。
- 提现申请：会员在会员中心发起（微信 / 支付宝），后台审核通过/拒绝。

### 支付设置（真实商户号，v3.17）

- **支付模式**：
  - **自动模式**（推荐）：微信 / 支付宝各自按「商户号参数是否填写完整」自动切换真实支付或模拟支付；
  - **仅测试模式**：即使填了商户号也只走模拟收银台（本地调试用）。
- **微信支付（Native 扫码，APIv2）**：填微信商户号 MchID、公众号 AppID、APIv2 密钥 Key（商户平台 → 账户中心 → API 安全 → 32 位密钥）；**退款证书**填服务器上 `apiclient_cert.pem` / `apiclient_key.pem` 的**绝对路径**（不填则真实退款不可用，退款走钱包）。
- **支付宝（当面付扫码，RSA2）**：填应用 AppID、**应用私钥**（PKCS8，可含或省略 BEGIN 标记）、**支付宝公钥**（开放平台 → 应用详情 → 接口加签方式查看）。
- **模拟支付 / 线下转账**：前台收银台选项开关（测试环境默认开启）。
- **回调地址**：微信 `/shop/notify_wechat`（XML 异步通知）、支付宝 `/shop/notify_alipay`（表单异步通知），**必须外网可访问**；本地 / 内网无法接收回调时，前台支付页会自动**轮询订单状态**（每 5 秒），付款完成后自动跳转，无需人工处理。
- 前台收银台：配置真实商户号后，微信显示 Native 扫码二维码、支付宝显示当面付二维码；未配置商户号时显示「模拟收银台」按钮（点击即支付成功），并保留线下转账选项。



## 十五·C、采集器（扩展功能 → 采集器）

抓取外部网站列表与文章正文，自动入库到指定栏目。规则字段与配置要点如下（**配置错误是采集失败的绝对主因**）：

- **列表地址**：列表页 URL。**翻页用 `{page}` 占位符**，如 `https://www.lnjchbsb.com/news/page/{page}`，配合「最大翻页数」（该站共几页填几）。只填固定第 1 页地址则永远只抓第 1 页。
- **列表起始 / 列表结束**：从列表页**源码**中选取唯一标记，把中间区域圈出来（采集器只在该区域内找链接）。例：起始 `<ul class="list-5">`、结束 `</ul>`。圈得越窄越不会抓到导航/翻页链接。
- **链接正则**：从圈定区域提取详情页链接，**必须带一个捕获组**（第 1 组为 URL）。例：`#<a href="([^"]+)"[^>]*title="[^"]+"#is`。留空则用默认正则抓区域内全部 `<a href>`，可能混入无关链接。
- **标题起始 / 标题结束**：详情页标题的起止标记。例：起始 `<h1>`、结束 `</h1>`（取两标记之间的文本作为标题）。**必填**——不填会把整页 HTML 文本当标题，超长直接导致整条采集失败。
- **正文起始 / 正文结束**：详情页正文容器起止标记。例：起始 `<div class="yunu-infocontent-body">`、结束 `</div>`（正文容器内不能再有同名嵌套标签）。**必填**——不填会把整页源码当正文入库。
- **字符集**：目标站是 GBK 填 GBK，UTF-8 填 UTF-8（默认）。
- **图片下载**：开启后自动把正文图片下载到本地 `upload/image/` 并替换为本地地址，同时取正文第一张图为缩略图。
- **过滤词**：逗号分隔，标题含任一词即跳过该条。
- **执行结果**：日志显示「抓取 X 条，新增 Y，跳过 Z，失败 N」。常见失败原因：标题/正文起止标记未填或标记错（最典型，表现为 **failed=N 且 added=0**）、列表起止圈错区域、链接正则无捕获组、目标站反爬。





* 系统内置 `{yunu:xxx}` 标签库，**云优前台模板可直接放入&#x20;**`template/{语言目录}/`**&#x20;使用**（配合云优数据库导入 `database/migrate_yunu_to_yiyun.sql` 后即可运行）。

* 富文本已用云优同款 **UEditor**；头条 / 推荐 / 多图 / 描述等字段与云优对齐。

### 常见问题
| 现象 | 处理 |
|---|---|
| 页面 500 报 `site_url()` 参数不足 | 清 `runtime/index/temp` + `runtime/cache`（TP6/TP8 编译缓存）；旧 taglib 字节码被 opcache 缓存时重启 php-cgi |
| 列表链接带 `cn` 前缀 | 后台「系统设置-伪静态」重新保存一次，自动重写 `public/nginx.htaccess` |
| 栏目静态路径出现 `news/news/` 重复 | 栏目 ename 必须是**叶子名**（不含 `/`），`UPDATE yy_cn_category SET ename=SUBSTRING_INDEX(ename,'/',-1) WHERE ename LIKE '%/%'` 后重新生成静态 |
| 模板里数字栏目 ID 不对 | 重新生成 `id_map.json` 后重跑转换器 |
