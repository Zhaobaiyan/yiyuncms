## 一、多语言下的 URL 与链接函数

模板中**不要手写** `/lists/index?id=2` 这类硬编码（en 需要 `/en/` 前缀）。用以下模板可调用的全局函数：



| 表达式                                      | 作用                                                    |
| ---------------------------------------- | ----------------------------------------------------- |
| `{:site_url('lists','index',['id'=>2])}` | 列表页链接，自动带语言前缀                                         |
| `{:url_cat($category)}`                  | 栏目链接（静态优先，否则动态）                                       |
| `{:url_content($content)}`               | 内容详情链接（静态优先）                                          |
| `{:url_home()}`                          | 首页链接                                                  |
| `{:url_homepage()}`                      | 引导页「进入网站」正常首页链接（主语言 `/home`，其他语言 `/{lang}/home.html`） |
| `{:url_lang('en')}`                      | 切换到 en 语言首页                                           |
| `{:lang_code()}`                         | 当前语言代码                                                |
| `{:lang_codes()}`                        | 所有已启用语言代码数组（可 foreach）                                |
| `{:lang_is_default()}`                   | 当前是否为默认语言（主语言）                                        |

### 多语言静态 URL 规则（v3.2，开启静态化后）



* **主语言（默认语言，如 cn）**：链接**无语言前缀** —— 首页 `/`、栏目 `/news/`、单页 `/aboutus/about.html`、内容 `/pro/pro1/1/16.html`；列表栏目链接统一**带尾斜杠**（`/news/`、`/pro/pro1/`）。

* **其他语言（如 en）**：链接**带前缀** —— 首页 `/en/`、栏目 `/en/news/`、单页 `/en/about.html`、内容 `/en/news/12.html`。

* 上述链接由 `url_cat()/url_content()/site_url()` 自动生成，模板中直接使用即可。

* **栏目静态 URL 规则开关**（后台 系统设置 → 静态页设置 → `base.static_url_mode`）：


  * **精准链接（accurate，默认）**：栏目与内容静态路径拼接全部祖先别名，URL = 域名 + 一级 + 二级 + 三级 + 详情页（如 `/pro/pro1/1/16.html`），单页也带父层级（`/aboutus/about.html`）。

  * **精简链接（compact）**：只保留最后栏目与详情页（如 `/pro1/1/16.html`）。

  * 切换开关或改栏目别名后，需在后台「静态页生成」重新生成全站静态页。

### 语言切换示例



```
{foreach :lang_codes() as $lc}

  <a href="{:url_lang($lc)}" class="{if $lc == lang_code()}on{/if}">

    {if $lc=='cn'}中文{elseif $lc=='en'}EN{else}{$lc}{/if}

  </a>

{/foreach}
```

> 新增第三语言后建议改为动态输出语言名（遍历 yy_lang 表取 name），不再用两分支硬编码。

### 设备切换示例（电脑版 / 手机版）



```
{if $is_wap}

  <a href="{:site_url('device','set',['client'=>'pc','back'=>$cur_url])}">电脑版</a>

{else}

  <a href="{:site_url('device','set',['client'=>'mobile','back'=>$cur_url])}">手机版</a>

{/if}
```

`$is_wap` 当前是否手机版；`$cur_url` 当前页地址（FrontBase 注入）。

### 搜索表单（全站 / 指定栏目、标题 / 正文）



```
<form action="{:site_url('search','index')}" method="get">

  <input type="hidden" name="field" value="all">

  <select name="catid">

    <option value="0">全站</option>

    {cms:category parent="0" item="cat"}

      <option value="{$cat.id}" {if isset($catid) && $catid==$cat.id}selected{/if}>{$cat.name}</option>

    {/cms:category}

  </select>

  <input type="text" name="kw" value="{if isset($kw)}{$kw}{/if}" placeholder="搜索标题或正文">

  <button type="submit">搜索</button>

</form>
```

搜索参数：`kw` 关键词、`catid` 栏目（0 全站）、`field`（all 标题 + 正文 /title 仅标题 /content 仅正文）、`page` 页码。每页条数由后台 `content.pagesize` 控制（默认 10）。

## 二、标签总览（{cms:xxx}）



| 标签                | 类型       | 说明                   |
| ----------------- | -------- | -------------------- |
| `{cms:setting}`   | 单标签      | 输出当前语言站点配置           |
| `{cms:list}`      | 双标签 (循环) | 内容列表                 |
| `{cms:category}`  | 双标签 (循环) | 栏目列表                 |
| `{cms:nav}`       | 双标签 (循环) | 导航栏目（含子栏目）           |
| `{cms:block}`     | 单标签      | 自定义块内容（支持图片两种调用）     |
| `{cms:ad}`        | 单标签      | 广告位内容                |
| `{cms:link}`      | 双标签 (循环) | 友情链接                 |
| `{cms:crumbs}`    | 双标签 (循环) | 面包屑                  |
| `{cms:prevnext}`  | 双标签      | 上一篇 / 下一篇            |
| `{cms:content}`   | 单标签      | 单条内容，之后可用 `$content` |
| `{cms:hot}`       | 双标签 (循环) | 浏览量排行                |
| `{cms:pagetitle}` | 单标签      | SEO 标题拼接             |
| `{cms:catfield}`  | 单标签      | **当前栏目自定义字段值（v3.0）** |

> 双标签 = 有开始 / 结束标签，中间为循环体；单标签 = 自闭合直接输出。

## 四、标签详解

### 1. `{cms:setting}` 站点配置



```
{cms:setting name="site.name" /}           <!-- 网站名称 -->

{cms:setting name="site.copyright" /}      <!-- 版权 -->

{cms:setting name="site.icp" default="京ICP备...号" /}  <!-- 带默认值 -->
```

属性：`name`（必填，点语法如 `site.name`）、`default`（可选）。读当前语言 yy_{lang}_setting，多语言独立。

### 2. `{cms:list}` 内容列表（双标签循环）



```
{cms:list catid="2" num="10" order="list" item="vo"}

<!-- 不写 num：自动按该栏目「栏目管理 → 每页」设置的条数（默认10）；写明 num 则以代码为准 -->

  <h3><a href="{:url_content($vo)}">{$vo.title}</a></h3>

  <p>{$vo.description}</p>

  <span>{$vo.create_time|date='Y-m-d'} 浏览：{$vo.views}</span>

{/cms:list}
```



| 属性         | 默认   | 说明                                                                |
| ---------- | ---- | ----------------------------------------------------------------- |
| `catid`    | 0    | 栏目 ID；0 全部，支持逗号分隔（如 `2,3`），自动包含子栏目；`catid="current"` 当前栏目（v3.6.6） |
| `num`      | 10   | 数量                                                                |
| `order`    | list | 枚举：`list`(默认，置顶+排序+时间)/`views`/`update`/`time`/`rand`；v3.8.10 起可直接写多字段排序字符串，如 `order="sort desc, create_time desc, id desc"`（字段对照见 3.x 小节） |
| `model_id` | 0    | 内容模型 ID，0 不限                                                      |
| `flag`     | ''   | 推荐标记：`recommend`/`top`/`hot`，可逗号组合                                |
| `where`    | ''   | 附加 SQL 条件（谨慎，如 `views>100`）                                       |
| `item`     | vo   | 循环变量名                                                             |
| `key`      | k    | 序号变量名                                                             |

### 2・A. 循环计数 / 隔行样式 / 头条标记（对应云优 PHP 计数写法）

云优模板常用一段 PHP 变量做循环计数（隔行换色、编号），易云 `{cms:list}` 已内置序号变量 `$k`（从 0 开始），无需手写计数：

**云优写法（PHP 内联计数）**：

```
<?php $xinwen = 0;?>
<yunu:list cid="108" titlelen="30" orderby="update_time desc" limit="4" flag="0" top="0" tag="">
{$xinwen}
<?php $xinwen++;?>
</yunu:list>
```

**易云写法（内置序号）**：

```
{cms:list catid="108" num="4" order="update_time" item="vo" key="k"}
  {$k}                                        <!-- 序号：0,1,2,3...（与云优 $xinwen 一致） -->
  {$k+1}                                      <!-- 序号从 1 开始：1,2,3,4...（{$k+N} 即从 N 开始） -->
  <div class="{if $k % 2 == 0}xinwendan{else}xinwenshuang{/if}">  <!-- 奇偶隔行 -->
    <a href="{:url_content($vo)}">{$vo.title}</a>
    {if $vo.top == 1}
    <div class="chanpinlistexin"></div>        <!-- 头条标记 -->
    {/if}
  </div>
{/cms:list}
```

**对应关系**：

| 云优写法 | 易云写法 |
|---|---|
| `<?php $xinwen = 0; ?>` + `{$xinwen}` + `<?php $xinwen++; ?>` | `key="k"` 后用 `{$k}`（内置序号，0,1,2...） |
| `<if condition="ceil($xinwen/2)-$xinwen/2 == 0">...<else>...</if>` | `{if $k % 2 == 0}...{else}...{/if}` |
| `<if condition="$list.top == 1">...<else>...</if>` | `{if $vo.top == 1}...{/if}` |

说明：`$vo` 为内容循环变量（`item="vo"` 默认）、`$k` 为序号（`key="k"` 默认，从 0 开始，与云优 `$xinwen` 完全一致）；**序号偏移直接用运算：从 1 开始写 `{$k+1}`、从 2 开始写 `{$k+2}`，从 N 开始写 `{$k+N}`**（模板引擎支持变量运算）；`$vo.top` 为头条等级（0 非头条，1~9 级，与云优一致），判断"是头条"可简写 `{if $vo.top}`。若直接使用 `{yunu:list}` 兼容层，循环变量是 `$list`，对应 `$list.top`、`$list.url`、`$list.title`，标题截断用 `{$list.title|mb_substr=0,30}`；`{yunu:list}` 无内置序号，需要计数时仍可沿用云优的 PHP 内联写法（模板支持原生 `<?php ?>`）。

### 3. `{cms:category}` 栏目列表（双标签循环）



```
{cms:category parent="0" item="cat"}

  <a href="{:url_cat($cat)}">{$cat.name}</a>

{/cms:category}
```



| 属性         | 默认  | 说明                                                              |
| ---------- | --- | --------------------------------------------------------------- |
| `id`       | ''  | 单条栏目：`id="5"`；`id="current"` 当前栏目；`id="parent"` 当前栏目的父级（v3.6.6） |
| `parent`   | 0   | 父栏目 ID；0 顶级，-1 全部；`parent="current"` 当前栏目父级下的同级栏目列表（v3.6.6）     |
| `top`      | 0   | `top="1"` 输出**当前栏目的顶级栏目单条**，配合 `deep` 展开其子级（v3.6.6）             |
| `deep`     | 0   | 子栏目递归深度（`haschild="1"` 等价 `deep="1"`；`deep="2"` = 子级 + 孙级）      |
| `type`     | ''  | 栏目类型过滤：`list`/`single`/`external`                               |
| `num`      | 20  | 数量                                                              |
| `haschild` | 0   | 是否同时加载子栏目（`$cat.children` 为数组）                                  |
| `item`     | cat | 循环变量名                                                           |

每项额外附带两个选中标记（v3.6.6）：



| 字段                 | 说明                            |
| ------------------ | ----------------------------- |
| `$cat.active`      | 当前栏目**或其祖先** = 1（用于父级 / 祖级高亮） |
| `$cat.active_self` | **仅当前栏目本身** = 1（用于当前栏目高亮）     |

### 3・A. 当前栏目 / 父级 / 顶级与选中高亮（v3.6.6，无需填固定 ID）

列表页、详情页自动识别当前栏目（列表页取栏目 ID，详情页取内容所属栏目）。

**① 当前栏目单条**：



```
{cms:category id="current" item="cat"}

当前栏目：{$cat.id} - {$cat.name} - {$cat.ename}

{$cat.description}　{$cat.image}

{/cms:category}
```

**② 当前栏目的父级单条**：



```
{cms:category id="parent" item="pa"}

父级栏目：{$pa.id} - {$pa.name}　{$pa.url}

{/cms:category}
```

**③ 当前栏目父级下的同级栏目列表**（侧栏 "本栏目同级导航" 常用，当前栏目自动高亮）：



```
{cms:category parent="current" item="p"}

<a href="{:url_cat($p)}" class="{if $p.active}on{/if}">{$p.name}</a>

{/cms:category}
```

**④ 顶级栏目单条**（当前栏目向上找到顶级）：



```
{cms:category top="1" item="t"}

顶级栏目：{$t.id} - {$t.name}

{/cms:category}
```

**⑤ 顶级 + 子级 + 孙级**（从顶级展开三级，自动高亮选中链）：



```
{cms:category top="1" deep="2" item="t"}

<a href="{:url_cat($t)}" class="{if $t.active}on{/if}">{$t.name}</a>

{foreach $t.children as $c2}

  <a href="{:url_cat($c2)}" class="{if $c2.active}on{/if}">{$c2.name}</a>

  {foreach $c2.children as $c3}

    <a href="{:url_cat($c3)}" class="{if $c3.active_self}on{/if}">{$c3.name}</a>

  {/foreach}

{/foreach}

{/cms:category}
```

> 选中标记说明：
> `active=1`
> 表示该项是当前栏目或当前栏目的某个祖先（顶级、父级、父级的父级都会高亮）；
> `active_self=1`
> 表示该项就是当前栏目本身。写导航高亮用
> `active`
> 即可同时实现 "当前栏目 + 所有祖先" 高亮。

**⑥ 当前栏目内容列表**（不写死 ID）：



```

### 4. `{cms:nav}` 导航栏目（双标签循环）



```
{cms:nav item="n"}

  <a href="{:url_cat($n)}">{$n.name}</a>

  {if isset($n.children)}

    {foreach $n.children as $c}<a href="{:url_cat($c)}">{$c.name}</a>{/foreach}

  {/if}

{/cms:nav}
```

属性：`item`（默认 nav）、`key`。只返回顶级（`is_nav=1` 且 `parent_id=0`），子栏目放 `$n.children`。

**判断是否有二级导航（对应云优 `<if condition="$nav.child">`）**

易云使用 TP6 模板引擎，云优的 `<if condition="...">` 老写法要换成 `{if}` 标签，对照如下：

| 云优（TP3）写法 | 易云（TP6）写法 |
|---|---|
| `<if condition="$nav.child">` | `{if $n.children}` |
| `<else>` | `{else}` |
| `</if>` | `{/if}` |
| `{volist name="nav.child" id="v"}` | `{foreach $n.children as $c}` |
| `{$nav.title}` | `{$n.name}` |

完整示例（有二级时输出下拉菜单，无二级时只输出名称）：

```
{cms:nav item="n"}
  <a href="{:url_cat($n)}">{$n.name}</a>
  {if $n.children}
  <ul class="sub-menu">
    {foreach $n.children as $c}
    <li><a href="{:url_cat($c)}">{$c.name}</a></li>
    {/foreach}
  </ul>
  {/if}
{/cms:nav}
```

若要显式区分有/无两分支：

```
{cms:nav item="n"}
  {if $n.children}
    有二级导航：{$n.name}（这里输出子栏目）
  {else}
    无二级导航：{$n.name}
  {/if}
{/cms:nav}
```

说明：`$n` 为循环变量名（`item="n"` 指定，默认是 `$nav`）；没有二级时 `$n.children` 为空数组，`{if $n.children}` 自动为假、不会报错，比 `{if isset($n.children)}` 更贴合"是否有二级"的语义；三级以上继续用 `$c.children` 嵌套。云优模板直接用 `{yunu:nav}` 兼容层时同理：`{if $nav.child}`、`{foreach $nav.child as $v}`。

导航每项同样附带 `active` / `active_self` 选中标记（v3.6.6），顶部主导航高亮直接使用：



```
{cms:nav item="n"}

<a href="{:url_cat($n)}" class="{if $n.active}on{/if}">{$n.name}</a>

{/cms:nav}
```

## 七、列表分页

前台列表页与搜索页分页条直接用：



```
<div class="pagination">{$list|raw}</div>
```



* 每页条数：各栏目单独设置（后台「栏目管理 → 每页」，默认 10；`{cms:list num="N"}` 写明 N 则以代码为准）。

* **翻页样式**：后台「网站设置 → 前台翻页样式」可配置：


  * 翻页数字模式：**完整数字**（不超过 15 页全部显示，超过则 前 3 … 后 3）或 **固定滑动窗口**（第 1 页显示 1..N，第 2 页显示 2..N+1，默认 N=7）。

  * 是否显示「首页 / 尾页」按钮（默认显示；不需要时关闭）。

* 翻页输出结构为 `<ul class="pagination">`：`首页 | « 上一页 | 数字页码 | 下一页 » | 尾页`，当前页 `<li class="active">`、不可点击 `<li class="disabled">`。

* **样式如何改**：结构不变，样式在模板引用的前台 CSS（`static/front/css/yunu.css`）中查找 `.pagination` 系列规则修改即可（颜色 / 圆角 / 间距等）；也可在模板页面内加 `<style>` 覆盖。

### 列表序号（页内 1~N / 全站连续序号）

列表页标准循环用控制器注入的 `$list`（分页对象）与 `$key`（页内下标，从 0 开始）：

```
{foreach $list as $key=>$vo}
  <span class="no">{$key+1}</span>                        <!-- 页内序号：每页都从 1 开始 -->
  <a href="{:url_content($vo)}">{$vo.title}</a>
{/foreach}
```

**每页都从 1 开始（页内序号）**：`{$key+1}` 即可（第一页 1~10，第二页也是 1~10）。

**全站连续序号（第一页 1~10，第二页 11~20）**：用当前页码 `$page` 和栏目每页条数 `$category.pagesize` 计算，模板有两种写法（均已实测）：

写法一（`{~赋值}` 计算标签，推荐）：

```
{foreach $list as $key=>$vo}
  {~$no = ($page-1)*$category['pagesize']+$key+1;}
  <span class="no">{$no}</span>
  <a href="{:url_content($vo)}">{$vo.title}</a>
{/foreach}
```

写法二（原生 PHP）：

```
{foreach $list as $key=>$vo}
  <span class="no"><?php echo ($page-1)*$category['pagesize']+$key+1; ?></span>
  <a href="{:url_content($vo)}">{$vo.title}</a>
{/foreach}
```

说明：`$page` 为当前页码（第 2 页 = 2）、`$category['pagesize']` 为栏目每页条数（后台栏目管理设置，默认 10）。公式 `(page-1)*pagesize + key + 1`：第一页 `(1-1)*10+0+1=1`…第 10 条 `=10`；第二页 `(2-1)*10+0+1=11`…`=20`。若每页条数不是 10，公式自动适配。`{$key+1}` 与 `{~$no=...}` 均已通过模板引擎实测。

### 查看更多（加载更多）分页（与翻页相互独立，模板自行二选一）

翻页（`{$list|raw}`）与「查看更多」是两套互不影响的样式：**同一个模板二选一**，不同栏目模板可以一个用翻页、另一个用查看更多。



1. 列表容器：给列表循环的 `<ul>` 加 `id="yy-list"`（内置 list_news /list 模板已加）。

2. 把翻页块 `<div class="pages">{$list|raw}</div>` 替换为「查看更多」按钮：



```
<div class="pages">

  <a href="javascript:;" class="yy-load-more"

     data-url="{:site_url('lists','more')}"

     data-cid="{$category.id}"

     data-offset="{$more_offset}"

     data-size="5"

     data-target="#yy-list">查看更多</a>

</div>
```



| 属性            | 说明                                   |
| ------------- | ------------------------------------ |
| `data-url`    | 加载接口地址（自动带语言前缀，en 站为 /en/lists/more） |
| `data-cid`    | 当前栏目 ID                              |
| `data-offset` | 首屏已显示条数（模板自动输出 `$more_offset`，无需手改）  |
| `data-size`   | **每次点击追加条数，代码中写**（如 5、10，可与首屏每页条数不同） |
| `data-target` | 列表容器选择器（默认 #yy-list）                 |



1. 交互逻辑（内置 yunu.js 已实现，无需额外引入）：

* 首屏显示数量 = 栏目「每页」设置（默认 10 条）。

* 点击「查看更多」→ 下方继续追加 `data-size` 条（如 5 条），按钮位置不变。

* 追加数量不足 `data-size`（最后一批）或已无内容 → 按钮自动变为「没有更多了」并禁用。

* 加载中按钮显示「加载中...」，失败提示后恢复。

> 静态生成模式下列表页固定为翻页样式（生成时不含查看更多按钮），查看更多适合纯动态模式使用。



* 列表页 URL：`/lists/index?id={栏目ID}&page=N`（en 为 `/en/lists/index?id=...&page=N`）。

* 搜索页分页自动保留 `kw/catid/field` 参数。

## 九、模板注意要点



* **默认过滤器**：`{$var|default='x'}` 只用于输出上下文；`{if}` 条件里用 `{if isset($var) && $var == 'x'}`。

* **正文输出**：带 HTML 内容用 `{$item.content|raw}`、`{$item.desc|raw}`。

* **附件下载（v3.4）**：正文 / 描述 / 单页 / 自定义块中由后台插入的**附件链接**（`/upload/` 下的 doc/pdf/zip 等非图片文件）在前台自动重写为下载端点：点击即下载，文件名 = 后台编辑器里该链接的文字（可改名）+ **原文件后缀**（如 `网站确认书.doc`），无需手动补后缀；图片链接保持 `<img>` 直出不受影响。模板无需任何特殊标签，直接 `{$content.content|raw}` / `{$item.desc|raw}` 输出即可。

* **时间格式化**：`{$item.create_time|date='Y-m-d H:i'}`。

* **分页**：`{$list|raw}` 输出分页条。

* **改模板后**：清空 `runtime/temp` 再刷新（模板编译缓存）。

* **多语言**：所有前台链接用 `site_url/url_cat/url_content`，禁止硬编码 `/lists`、`/show`。

* **模板命名规范（云优）**：首页 `index_index.html`、列表 `list_xxx.html`、内容 `show_xxx.html`；栏目管理下拉自动识别。

* **模板资源（**`__PUBLIC__`**）**：模板中的 `__PUBLIC__/` 前缀自动解析为模板资源入口（`/assets/index?path=`），读取 `template/{当前语言}/` 下的资源。资源物理存放于模板同级目录：`template/cn/css/`、`template/cn/js/`、`template/cn/images/`、`template/cn/fonts/` 等。用法：`<link rel="stylesheet" href="__PUBLIC__/css/yunu.css">`、`<script src="__PUBLIC__/js/yunu.js"></script>`、`<img src="__PUBLIC__/images/nopic.jpg">`。新增语言（如 en）把资源放入 `template/en/` 即可，当前语言缺失自动回退主语言资源。

### 云优 → 易云 标签写法逐条对照（v3.8）

以下为常见云优模板标签块与易云原生写法的完整对照（字段已按 v3.8 云优键统一，`{$vo.pic}`/`{$vo.desc}`/`{$vo.update_time}` 等原生 `{cms:list}` 可直接使用）：

**1. 导航 `{yunu:nav}` → `{cms:nav}`**

```
<yunu:nav typeid="1" limit="10" orderby="sort desc , create_time desc , id desc">
  <li><a href="{$nav.url}">{$nav.title}</a></li>
</yunu:nav>
```

```
{cms:nav item="nav"}
  <li><a href="{:url_cat($nav)}">{$nav.name}</a></li>
{/cms:nav}
```

说明：`typeid`/`orderby` 在云优兼容层本就忽略（只输出顶级导航，按 sort 排序）；易云 `{cms:nav}` 同样只输出顶级（is_nav=1 且 parent_id=0）。字段：`$nav.title`→`$nav.name`、`$nav.url`→`{:url_cat($nav)}`；子栏目 `$nav.children`（yunu 键 `child`）。

**2. 子栏目列表 `{yunu:catlist type="son"}` → `{cms:category parent}`**

```
<yunu:catlist cid="$cid" type="son" limit="10" flag="0" orderby="sort desc , create_time desc , id desc">
  <a href="{$catlist.url}">{$catlist.title}</a>
</yunu:catlist>
```

```
{cms:category parent="{$cid}" item="cat"}
  <a href="{:url_cat($cat)}">{$cat.name}</a>
{/cms:category}
```

`parent="{$cid}"`（列表页已注入当前栏目 ID）也可写 `parent="current"` 自动取当前栏目。

**3. 同级栏目列表 `{yunu:catlist type="self"}` → `{cms:category parent="current"}`**

```
<yunu:catlist cid="$cid" type="self" limit="10" flag="0" orderby="sort desc , create_time desc , id desc">
  <a href="{$catlist.url}">{$catlist.title}</a>
</yunu:catlist>
```

```
{cms:category parent="current" item="cat"}
  <a href="{:url_cat($cat)}">{$cat.name}</a>
{/cms:category}
```

`parent="current"` = 当前栏目父级下的同级栏目，与云优 self 一致。

**4. 单栏目 `{yunu:type}` → `{cms:category id}`**

```
<yunu:type typeid="8">
  <a href="{$type.url}">{$type.title}</a>
</yunu:type>
```

```
{cms:category id="8" item="cat"}
  <a href="{:url_cat($cat)}">{$cat.name}</a>
{/cms:category}
```

**5. 内容列表 `{yunu:list}` → `{cms:list}`**

```
<yunu:list cid="$cid" orderby="id desc" limit="10" flag="0" top="0" tag="">
  <a href="{$list.url}"><img src="{$list.pic}" alt="{$list.title}"></a>
  <span>{$list.update_time|date='Y-m-d',###}</span>
  <p>{$list.desc|str2sub=20, true}</p>
</yunu:list>
```

```
{cms:list catid="{$cid}" num="10" item="vo"}
  <a href="{:url_content($vo)}"><img src="{$vo.pic}" alt="{$vo.title}"></a>
  <span>{$vo.update_time|date='Y-m-d',###}</span>
  <p>{$vo.desc|strip_tags|mb_substr=0,20}</p>
{/cms:list}
```

说明：`flag="0"`/`top="0"`/`tag=""` 均为默认（不过滤/不限定），易云不写即默认；`str2sub=20` 截断 → `mb_substr=0,20`（desc 是简易富文本含 HTML，先 `strip_tags` 再截断）。**排序完全兼容（v3.8.10 起）**：`orderby="sort desc , create_time desc , id desc"` 这类云优多字段排序可直接使用（字段对照见 3.x 小节），`{yunu:list}` 与 `{cms:list}` 均支持；`{cms:list}` 的 `order` 枚举（`list`/`views`/`update`/`time`/`rand`）仍可用。

**排序字段对照（orderby / order 多字段排序，v3.8.10）**

| 云优字段        | 易云实际字段   | 说明                                  |
| ------------- | ---------- | ----------------------------------- |
| `id`          | `id`       | 录入顺序（正序=先录入在前，反序=后录入在前）           |
| `sort`        | `sort`     | 后台栏目/内容排序值（数字，越小越靠前）              |
| `listorder`   | `sort`     | 云优 listorder 别名                      |
| `create_time` | `create_time` | 发布时间（键名一致，无需转换）                    |
| `update_time` | `update_time` | 更新时间                              |
| `click`       | `views`    | 浏览量（云优 click 别名）                    |
| `views`       | `views`    | 浏览量                                |
| `top` / `is_top` | `top` / `is_top` | 头条 / 置顶标记                        |
| `is_recommend` / `is_hot` | 原样 | 推荐 / 热门标记                |
| `rand`        | `RAND()`   | 随机                                  |

- 写法：逗号分隔多段，每段 `字段 方向`，方向 `asc`（正序/从小到大）或 `desc`（反序/从大到小），**缺省 asc**。
- 例：按发布时间反序 `orderby="create_time desc"`（新在前）；按后台排序正序再时间反序 `orderby="sort asc, create_time desc, id desc"`。
- `{cms:list}` 同样支持：`{cms:list catid="2" num="10" order="sort desc, create_time desc, id desc" item="vo"}`。
- 未知字段自动忽略（白名单防注入）；列表页控制器分页（`{foreach $list}`）仍为固定排序 `置顶→排序→发布时间`。

**6. 轮播 / 广告 `{yunu:banner}` → `{cms:ad}`（单图）**

```
<yunu:banner type="0" orderby="id desc" limit="10">
  <li><a href="{$banner.url}"><img src="{$banner.pic}" alt="{$banner.title}"></a></li>

说明：易云广告位管理可上传多图列表，前台单图输出用 `{cms:ad name="标识" /}`（输出 image 或 content）；**轮播循环多图**建议保留 `{yunu:banner}`。

**7. 友情链接 `{yunu:link}` → `{cms:link}`**

## 十一、单页 / 跳转栏目 URL 规则与 catlist 子栏目键（v3.7.3）

### 8.1 单页（single）栏目 URL



* 单页栏目静态生成**双写**：`public/{主语言}/{ename}.html` + `public/{主语言}/{ename}/index.html`。

* 主语言访问两种形式均可：`/aboutus`（目录式）与 `/aboutus.html`（文件式）；其他语言为 `/{lang}/aboutus.html`。

* `url_cat()` 生成的链接为文件式 `/aboutus.html`（可在模板中直接使用）。

### 8.2 跳转（redirect）栏目与链式跳转



* redirect 栏目的 `external_url` 支持 `@栏目ID` / `@栏目ename` / `http(s)://` / `/路径`。

* `@数字` 在**导入云优数据时自动映射**为易云 ID（如云优 `@7` → 易云 `@67`），保证无感转换。

* 链式跳转：如 企业优势 (62) → @77 → 77 (solution1) → @67 → /aboutus.html，`url_cat()` 会递归解析到最终真实页面。

* redirect /external 栏目**不生成静态文件**、**不参与静态路径**（category_path 跳过跳转父级），导航链接自动落到最终目标。

### 8.3 {yunu:catlist} 子栏目键名



* 易云在 `children` 之外**同时输出云优兼容键 **`child`（`{$catlist.child}` 可用，二者内容一致）。

* 侧边栏经典用法（product 系列模板 `public_left.html`）：



```
{yunu:catlist cid="$cid" limit="20" type="parent" orderby="sort desc"}

<li class="{if $catlist.id eq $cid || $catlist.id eq $category.pid}active open{/if}">

  {if $catlist.child}<i class="arr"></i>{/if}

  <a href="{$catlist.url}">{$catlist.title}</a>

  {if $catlist.child}

  <div class="lanmu-box">

    {volist name="catlist.child" id="v"}

    <p><a href="{$v.url}">{$v.title}</a></p>

    {/volist}

  </div>

  {/if}

</li>

{/yunu:catlist}
```



* 说明：`type="parent"` 在云优语义下取**当前栏目所属顶级下的整棵子树**（含三级嵌套），易云已对齐该行为。

### 8.5 列表分页（v3.7.4 静态化）



* 列表模板输出：`{$page|raw}`（注意 `|raw`，否则分页 HTML 会被转义成文本）。

* **动态访问**：分页链接为 `/lists?id=栏目ID&page=2`。

* **静态生成后**：分页链接为 `/栏目路径/page/2.html`，文件生成在 `public/{语言}/栏目路径/page/2.html`；主语言无语言前缀，其他语言带 `/en/` 前缀。

* 静态生成按栏目 `pagesize`（后台栏目编辑可设，默认 10）自动计算总页数并逐页生成 `index.html` + `page/N.html`。

* 分页样式由网站设置 → 前台翻页样式配置（`base.page_mode` full/window、`page_window` 默认 7、`page_first_last` 首页 / 尾页开关、`page_full_limit` 省略阈值 15）。

* 首页 / 上一页 / 数字列表 / 下一页 / 尾页 结构与云优 `.pages` 一致。

### 8.6 顶部导航二级下拉（v3.7.4）



* `{yunu:nav typeid="59"}` 输出的顶级栏目带 `child` 键（与 `children` 一致），模板用 `{if $nav.child}` 渲染 `dropdown-box`。

* hover 显示二级导航不再受窗口宽度限制（yunu.js 已解除 `width>991` 判断）；点击导航右侧箭头也可展开 / 收起。

## 十二、多维联动筛选（扩展字段，v3.8.10）

内页列表多维筛选（如「地区：全部/吉林/辽宁/黑龙江 × 科目：全部/语文/数学/英语 × 班级：全部/一班/二班/三班」），默认全部显示全部内容，选中任一列过滤列表，可多列组合（如 吉林+语文+全部班级）。已实测验证。

### 9.1 原理

- 筛选维度 = 内容模型的自定义**下拉/单选字段**（如 area 地区、subject 科目、class 班级），录入内容时选择。
- 字段值存储于内容 extend JSON（`{"area":"吉林","subject":"语文","class":"一班"}`）。
- 列表页 URL 参数 `f_字段标识=值`（如 `?f_area=吉林&f_subject=语文`）即筛选条件，可多参数组合。
- **`{cms:list}` / `{yunu:list}` / 列表页控制器分页（`{foreach $list}`）三种写法均自动过滤**，无需改模板标签；未带参数时显示全部。首页等非列表页区块同样可用（带参数时过滤，不带则全量）。

### 9.2 后台设置步骤

1. 内容模型 → 编辑 → 新增字段：
   - 字段标识（调用名）：`area`；字段名称：地区；字段类型：下拉（单选）；选项：吉林,辽宁,黑龙江
   - 字段标识：`subject`；字段名称：科目；选项：语文,数学,英语
   - 字段标识：`class`；字段名称：班级；选项：一班,二班,三班
2. 录入内容时选择所属地区 / 科目 / 班级。
3. 栏目（列表页）模板中放置三列联动导航 + 列表（见 9.3）。

### 9.3 三列联动导航模板（列表页模板）

三列导航把「全部 / 各选项」做成链接（点击跳转、刷新式联动）。已注入 `$filters`（选中值数组）供高亮；未带参数时该数组为空，用 `isset` 判断安全。

```
<div class="filter clearfix">
  <div class="filter-row">地区：
    <a href="/lists?id={$cid}{foreach $filters as $fk=>$fv}{if $fk!='area'}&f_{$fk}={$fv}{/if}{/foreach}" class="{if !isset($filters.area)}on{/if}">全部</a>
    {cms:category parent="地区组栏目ID" item="a"}
    <a href="/lists?id={$cid}{foreach $filters as $fk=>$fv}{if $fk!='area'}&f_{$fk}={$fv}{/if}{/foreach}{if !isset($filters.area) || $filters.area!=$a.name}&f_area={$a.name}{/if}" class="{if isset($filters.area) && $filters.area==$a.name}on{/if}">{$a.name}</a>
    {/cms:category}
  </div>
  <div class="filter-row">科目：
    <a href="/lists?id={$cid}{foreach $filters as $fk=>$fv}{if $fk!='subject'}&f_{$fk}={$fv}{/if}{/foreach}" class="{if !isset($filters.subject)}on{/if}">全部</a>
    {cms:category parent="科目组栏目ID" item="s"}
    <a href="/lists?id={$cid}{foreach $filters as $fk=>$fv}{if $fk!='subject'}&f_{$fk}={$fv}{/if}{/foreach}{if !isset($filters.subject) || $filters.subject!=$s.name}&f_subject={$s.name}{/if}" class="{if isset($filters.subject) && $filters.subject==$s.name}on{/if}">{$s.name}</a>
    {/cms:category}
  </div>
  <div class="filter-row">班级：
    <a href="/lists?id={$cid}{foreach $filters as $fk=>$fv}{if $fk!='class'}&f_{$fk}={$fv}{/if}{/foreach}" class="{if !isset($filters.class)}on{/if}">全部</a>
    {cms:category parent="班级组栏目ID" item="c"}
    <a href="/lists?id={$cid}{foreach $filters as $fk=>$fv}{if $fk!='class'}&f_{$fk}={$fv}{/if}{/foreach}{if !isset($filters.class) || $filters.class!=$c.name}&f_class={$c.name}{/if}" class="{if isset($filters.class) && $filters.class==$c.name}on{/if}">{$c.name}</a>
    {/cms:category}
  </div>
</div>

<!-- 列表：控制器分页（自动按 f_ 参数过滤），翻页/查看更多均保持筛选 -->
<ul class="list">
{foreach $list as $vo}
  <li><a href="{:url_content($vo)}">{$vo.title}</a></li>
{/foreach}
</ul>
<div class="pages">{$list|raw}</div>
```

要点：

- 「全部」链接 = 去掉本列参数（其他列已选参数通过 `foreach $filters` 保留）；选中「全部」时 URL 不出现该列参数。
- 三列可任意组合：`/lists?id=86&f_area=吉林&f_subject=语文&f_class=一班` = 吉林语文一班。
- 若不想建栏目组（地区/科目/班级），也可把选项写死成静态链接（同一参数规则），如 `<a href="/lists?id={$cid}&f_area=吉林">吉林</a>`。
- 选中样式 `.on` 自行在 CSS 定义（高亮）。

### 9.4 说明与限制

- 筛选值来自 URL 参数（`f_` + 字段标识）；字段标识仅允许字母/数字/下划线（白名单），值走 SQL 参数绑定，无注入风险。
- 三种列表写法都会过滤：`{cms:list}`（TagService）、`{yunu:list}`（YunuService）、列表页控制器分页（Lists 控制器）；详情页 / 搜索页带 `f_` 参数同样过滤。
- 筛选页为动态访问（带参数），**不参与静态生成**；静态开关不影响筛选功能。无参数访问照常走静态。
- 栏目 pagesize（每页条数）照常生效；分页条数基于过滤后总数。
- `{$filters}` 仅在列表页控制器注入；非列表页模板使用请用 `isset($filters.字段)` 保护。

## 十、商城相关（独立页面，非 cms 标签，v3.15/3.17）

商城不使用 `{cms:xxx}` / `{yunu:xxx}` 标签，使用**独立控制器 + 独立模板**（`app/index/view/shop/*.html`，自带样式不继承前台模板），路由前缀 `/shop`：

| 页面 | 路由 | 说明 |
|---|---|---|
| 商城首页 | `/shop/index` | 商品列表（`yy_shop` 有价格且上架的内容） |
| 商品详情 | `/shop/goods?id=内容ID` | 含价格/库存/销量、**规格 SKU 下拉联动**（v3.17） |
| 购物车 | `/shop/cart` | 加购/改数量/删除 |
| 结算 | `/shop/checkout` | 收货信息 + 支付方式选择 |
| 提交订单 | `/shop/submit`（POST） | 事务+行锁，SKU 原子扣库存 |
| 支付 | `/shop/pay?id=订单ID` | 微信 Native / 支付宝当面付真实二维码（配置商户号后）+ 模拟收银台 + 线下转账；页面自动**每 5 秒轮询** `/shop/pay_status?id=` 完成跳转 |
| 我的订单 | `/shop/order_list` / `/shop/order_detail?id=` | 状态流转查看、确认收货 |
| 售后 | `/shop/refund_add` / `/shop/refund_list` | 退货退款申请与记录 |
| 钱包 | `/member/wallet` | 余额 / 提现（微信、支付宝） |

**商品规格 SKU（v3.17）**：后台「商城管理 → 商品价格」为商品设置规格模板并生成 SKU 组合（每个组合独立价格与库存，存 `yy_shop.specs` JSON 的 `_sku` 键）。前台商品详情页自动出现规格下拉，选择后**价格 / 库存 / 可购数量实时联动**，库存为 0 的组合自动禁选；加购 / 下单均按所选规格校验与扣减库存（防超卖）。无规格商品使用商品级价格与库存。

**真实支付（v3.17）**：后台「商城管理 → 支付设置」填写微信商户号（MchID/AppID/APIv2 Key，退款需证书路径）与支付宝商户号（AppID/应用私钥/支付宝公钥）后，前台支付页自动切换为真实扫码支付；未配置商户号时自动降级为「模拟收银台」（点击即支付成功），线下转账不受影响。回调端点 `/shop/notify_wechat`、`/shop/notify_alipay` 需外网可达；本地环境依赖支付页轮询完成订单。
