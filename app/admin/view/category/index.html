一、导航与栏目

主导航（自动读取导航开启的顶级栏目）：

{cms:nav item="vo"}
  <a href="{$vo.url}">{$vo.name}</a>
{/cms:nav}

栏目列表（parent=0 顶级，1 一级栏目，也支持栏目别名）：

{cms:category parent="0" item="vo"}
  <a href="{$vo.url}">{$vo.name}</a>（子栏目：{$vo.children|raw}）
{/cms:category}

当前栏目信息（列表页中可用）：

{cms:category id="5" item="vo"} {$vo.name} / {$vo.ename} / {$vo.description} {/cms:category}

栏目自定义字段（栏目编辑中添加的字段）：

{cms:catfield name="tel" /}

二、内容列表

指定栏目内容（catid 支持逗号分隔多栏目，0 为全站）：

{cms:list catid="5" num="10" item="vo"}
  <a href="{$vo.url}">{$vo.title}</a>　{$vo.create_time|date='Y-m-d'}
{/cms:list}

排序方式：order="list"(默认/置顶优先) / "views"(浏览量) / "update"(时间) / "rand"(随机)

按标记筛选（flag 可组合）：

推荐：{cms:list catid="5" num="6" flag="recommend" item="vo"}...{/cms:list}
头条：{cms:list catid="0" num="5" flag="top" item="vo"}...{/cms:list}
热门：{cms:list catid="5" num="8" flag="hot" item="vo"}...{/cms:list}
置顶+推荐：{cms:list catid="5" num="10" flag="top|recommend" item="vo"}...{/cms:list}

指定模型内容：model_id="2"；自定义条件：where="views>100"（谨慎使用）

内容字段速查：title 标题 / url 链接 / thumb 缩略图 / desc 描述 / content 正文 / create_time 发布时间 / views 浏览量 / is_top 置顶 / is_recommend 推荐 / is_hot 热门 / flag 标记

三、列表页翻页（list_xxx.html 模板）

每页条数由「栏目管理 → 每页」控制（默认 10 条，点按直接修改）；模板标签 {cms:list num="N"} 若写明 N，则以代码中的条数为准（不写 num 则按栏目每页条数）。翻页代码直接输出 $list 变量即可：

{$list|raw}

翻页同时配合内容列表：

{cms:list catid="5" item="vo"}
  <a href="{$vo.url}">{$vo.title}</a>　{$vo.create_time|date='Y-m-d'}
{/cms:list}
{$list|raw}

说明：上例不写 num，列表条数自动取该栏目的「每页」设置；写 num="N" 则固定 N 条。

四、内容详情页（show_xxx.html 模板）

详情页直接使用 $content 对象输出：

{$content.title}　{$content.create_time|date='Y-m-d H:i'}　浏览：{$content.views}
{$content.content|raw}

上一篇 / 下一篇：

{cms:prevnext} 上一篇：{$prev.title} 下一篇：{$next.title} {/cms:prevnext}

面包屑导航：

{cms:crumbs} {$vo.name} {/cms:crumbs}

五、通用调用

自定义块 / 广告 / 友情链接：

{cms:block name="tel" /}
{cms:ad name="index_banner" /}
{cms:link num="10" item="vo"} {$vo.name} {/cms:link}

站点配置（网站名称 / 地址 / LOGO / 备案号等）：

{cms:setting name="site.name" /}
{cms:setting name="site.url" /}
{cms:setting name="site.logo" /}
{cms:setting name="site.icp" /}

完整字段与参数见《前台标签调用手册》（docs/前台标签调用手册.md）。
